design-skills

デザイン・UI と文言のためのスキル 19個。clone すればすぐ使えます。

Claude CodeCodex

画面を作る

新しい画面や LP の見た目を決める

frontend-design
テンプレ臭くない、意図のある見た目にする指針
ui-ux-pro-max
スタイル・配色・フォント・UX ルールを検索できる設計データベース

動きと触り心地

アニメーションやジェスチャーを作る

animate
Web（React など）のアニメーションを作る
animate-expo
React Native / Expo の動きとジェスチャー
apple-design
Apple 流の滑らかで物理的な動きを Web に応用する

レビューと引き継ぎ

できた案を確かめ、開発に渡す

design-critique
使いやすさ・視覚的な階層・一貫性のフィードバック
accessibility-review
WCAG 2.1 AA に沿ったアクセシビリティ確認
design-handoff
寸法・トークン・状態をまとめた開発向け仕様書
design-system
デザインシステムの監査・文書化・拡張

文言を書く・直す

AI っぽさを消し、正確に伝える

ja-copy-polishオリジナル
倒置法や「完全に。」のような断片、誇張語など、日本語の AI 文体を直す。景品表示法・薬機法に触れそうな表現にも印を付ける
ux-copy
ボタン・エラー・空状態などの UI 文言
copywriting
LP や料金ページの文言を新しく書く
copy-editing
既にある文言を磨く、短くする
stop-slop
英語の AI っぽい書き癖を取り除く

マーケティング

成果につながるページと発信を考える

cro
ページやフォームの成約率を上げる改善
product-marketing
製品の立ち位置・対象者・口調をまとめた土台の資料
content-strategy
ブログなどで何を書くかを計画する

ユーザー調査

使う人を理解する

user-research
調査の計画、インタビューガイドの作成
research-synthesis
調査結果をテーマと示唆にまとめる

使い方

1git clone https://github.com/ZETTAI-INC/design-skills.git
2そのフォルダで Claude Code か Codex を開けば、すぐ使える
3どのプロジェクトでも使うなら bash install.sh

呼び出し方

Claude Code：/ja-copy-polish のように入力するか、内容に合う依頼をすると自動で使われます。
Codex：$ja-copy-polish のように指定するか、内容に合う依頼をすると自動で使われます。
