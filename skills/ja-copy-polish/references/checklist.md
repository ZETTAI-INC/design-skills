# 仕上げのチェック表

出す前に上から順に確認する。1つでも「はい」なら直す。

## 正確さ（最優先）
- [ ] 元の文と渡された資料にない数字・実績・固有名詞・機能を足していないか
- [ ] 元の文の数字、条件、期限、価格、注意書きを落としていないか
- [ ] 意味を強めていないか（「できる場合がある」→「できる」など）
- [ ] 「No.1」「業界初」「最安」「完全」「絶対」「必ず」「100%」「誰でも」に、根拠がないまま残っていないか
- [ ] 効果・効能（治る、痩せる、消える等）を言い切っていないか
- [ ] 「無料」「今だけ」「返金保証」に、条件と期間が抜けていないか

## 文の形
- [ ] 述語のない文（「完全に。」「圧倒的なスピード。」）がないか（見出し・ボタン・箇条書き、意図して1回だけ使うキャッチコピーを除く）
- [ ] 倒置（「変わります、〜が。」）がないか（意図して1回だけ使うキャッチコピーを除く）
- [ ] 文頭の「そして、」「だからこそ、」で溜めていないか
- [ ] 「〜。〜。〜。」と短い断片を並べていないか
- [ ] 同じ文末が3回以上続いていないか

## 論理の演出
- [ ] 「〜ではなく〜」「〜ではありません。〜です」の対比を演出していないか
- [ ] 「〜不要。〜不要。」と否定を並べていないか
- [ ] 前置き（「結論から言うと」「ここがポイント」）や、決め台詞の締め（「さあ、〜へ」）がないか
- [ ] 問いかけで始める文、三点セットが、1ページに2回以上ないか

## 言葉
- [ ] 強調語・誇張語（圧倒的、革新的、真の、劇的に）が、根拠なしに残っていないか
- [ ] 「実現します」「可能にします」「価値を提供します」を、具体的な変化に置き換えたか
- [ ] 「〜することができます」「〜を行います」「〜において」が残っていないか
- [ ] 物が人のように振る舞う文（「データが語る」）がないか
- [ ] ダッシュ（——）や感嘆符を乱用していないか

## 最後に
- [ ] 敬体と常体が混ざっていないか
- [ ] 書き手の口調・言葉選びを、理由なく変えていないか
- [ ] 「良くなった理由」を言えない変更が残っていないか（残っていれば元に戻す）
