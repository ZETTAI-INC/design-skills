# 日本語の AI 書き癖 一覧

- **禁止**：1回でも出たら直す。
- **上限**：意図して使うなら1つのページ（または1つの投稿）で1回まで。重ねたら直す。
- **例外**：見出し・ボタン・箇条書きは名詞で終えてよい。キャッチコピーは修辞を1つだけ使ってよい（SKILL.md の「例外」を参照）。
- ✓ の例に出てくる数字や内容は、説明のための仮のものです。実際に直すときは、元の文と資料にある事実だけを使い、足りなければ `[要確認: …]` を置きます。

直し方の基本は同じです。**言いたいことを、主語と述語のそろった普通の語順の文で、具体的な事実と一緒に書く。**

---

## A. 文の形

### A1. 述語のない断片（禁止。見出し・キャッチコピーは例外を参照）
副詞、形容詞、名詞だけで文を終え、言い切らない。
- ✗ 完全に。
- ✗ 圧倒的なスピード。そして、正確さ。
- ✗ それが、私たちの答え。
- ✓ 請求書の作成から送付までを自動化できます。
- ✓ 1件あたりの処理時間を、従来の約半分にしました。

直し方：「何が」「どうなる／どうする」を補う。補う事実がないなら、その文は消す。

### A2. 倒置法（禁止。キャッチコピーで意図した1回のみ例外）
述語を前に出し、主語や目的語を後ろに回す。
- ✗ 変わります、あなたの働き方が。
- ✗ 届けたい、本当の価値を。
- ✗ はじめよう、新しい毎日を。
- ✓ あなたの働き方が変わります。
- ✓ 〇〇を通じて、△△の価値を届けます。

### A3. 読点で溜める・区切る（禁止）
文頭の副詞や接続詞の後に読点を打って間を作る。形容を読点で並べて余韻を出す。
- ✗ そして、未来へ。
- ✗ 静かに、確実に、進化する。
- ✗ だからこそ、私たちは。
- ✓ 毎月の更新で、使える機能が増えていきます。

### A4. 「〜。〜。〜。」の断片連打（禁止。キャッチコピーも含む）
短い名詞句や言い切らない文を3つ並べてリズムを作る。
- ✗ シンプル。スマート。パワフル。
- ✓ 画面は3つだけで、初日から使いこなせます。

### A5. 同じ文末の連続と、そろった文の長さ（上限）
「〜です。〜です。〜です。」が3回続く。どの文も同じくらいの長さになる。
- 直し方：文末に「〜ます」「〜でした」「〜できます」などを混ぜる。短い文と長い文を混ぜる。ただし、変化をつけるために倒置や体言止めを使わない。

### A6. 「〜し、〜し、〜します」の連鎖（上限）
一文に動作を詰め込む。
- 直し方：2つまでにして、文を分ける。

## B. 論理の演出

### B1. 対比の演出「〜ではなく、〜」（禁止）
誰も言っていない考えを持ち出して否定し、「本当の答え」を示す。
- ✗ ただのツールではありません。パートナーです。
- ✗ 大切なのは、量ではなく質です。
- ✗ 問題は〇〇ではない。△△なのだ。
- ✓ 導入後も、担当者が月に1回、運用の見直しを手伝います。

直し方：言いたい側（Y）だけを、その根拠と一緒に書く。読み手の誤解を正す必要が本当にあるときは、正しい事実と根拠を書く。

### B2. 否定の列挙（禁止）
「〜不要」「〜なし」「〜ゼロ」を並べ、最後に「だけ」で締める。
- ✗ 設定不要。契約不要。待ち時間ゼロ。必要なのは、スマホだけ。
- ✓ アプリを入れれば、その日から使えます。最低契約期間はありません。

### B3. 三点セット（上限）
「速く、安く、美しく」「〇〇、△△、そして□□」のように、何でも3つでそろえる。
- 直し方：実際の数で書く。2つなら2つ。3つあっても、本当に3つとも言う必要があるかを確かめる。

### B4. 問いかけで始める（上限）
- ✗ 〜と思ったことはありませんか？
- ✗ なぜ、〇〇なのでしょうか。
- 直し方：答えを先に書く。問いかけは1ページに1回まで。

### B5. 予告・前置き（禁止）
- ✗ 結論から言うと、／ここがポイントです。／〜について解説します。／見ていきましょう。
- ✗ 実は、／ズバリ、／ご存じでしょうか。
- 直し方：前置きを消して本題から書く。

### B6. 決め台詞の締め（禁止）
- ✗ さあ、〇〇の時代へ。／未来は、ここから始まる。／あなたの挑戦を、私たちは応援します。
- ✗ いかがでしたか？／このように、〜。（直前の内容の繰り返し）
- 直し方：最後の段落は、次に取ってほしい行動か、最後の具体的な事実で終える。

## C. 言葉選び

### C1. 中身のない強調語・誇張語（禁止。根拠を添える場合だけ可）
圧倒的、革新的、画期的、究極の、最高の、真の、本質的な、まさに、次のレベル、新時代、唯一無二、劇的に、飛躍的に、〜と言っても過言ではありません
- 直し方：数字か具体的な変化に置き換える。「圧倒的に速い」→「表示までの時間を3秒から1秒にしました」。

### C2. 抽象的な決まり文句（禁止）
〜を実現します、〜を可能にします、価値を提供します、課題を解決します、体験を最適化します、可能性を広げます、新たな価値を創造します、ワンストップで、シームレスに、寄り添います
- 直し方：「何が」「誰にとって」「どう変わるか」を書く。「業務効率化を実現します」→「毎月の請求作業が2日から半日になります」。

### C3. 翻訳調・役所調（上限）
| 避ける | こう書く |
|---|---|
| 〜することができます | 〜できます |
| 〜を行います | 〜します（「確認を行う」→「確認する」） |
| 〜において／〜に関して | 〜で／〜について |
| 〜となっております | 〜です |
| 〜させていただきます（多用） | 〜します |
| 〜であると言えるでしょう | 〜です（言えないなら書かない） |
| それは〜です（英語の It の直訳） | 主語を名詞で書くか省く |
| 〜によって〜されます（受け身） | 誰が何をするかを能動で書く |

### C4. 物が人のように振る舞う（禁止）
- ✗ データが語る真実。／この一歩が、未来を変える。／数字が証明しています。
- ✓ 〇〇社の調査では、導入企業の7割が△△と答えました。

### C5. ぼかしの重ね（上限）
「〜かもしれません」「〜と考えられます」「〜と言えるでしょう」を重ねる。「さまざまな」「多くの」「幅広い」を根拠なく使う。
- 直し方：分かっていることは言い切る。分からないことは書かないか、「未確認」と明記する。数を言えるなら数で書く。

### C6. カタカナ語の多用（上限）
ソリューション、エンゲージメント、インサイト、シナジー、アジェンダ、コミット、エンパワー
- 直し方：日本語で言えるものは日本語にする。業界の読み手が普段使う語なら残す。

## D. 記号と見た目

### D1. ダッシュ・コロンで溜める（禁止）
「——」「―」「：」で間を作ってから言い切る。
- ✗ 答えは一つ——〇〇です。
- ✓ 〇〇が答えです。

### D2. かぎかっこ・太字・絵文字の乱用（上限）
強調のための「」、1段落に何か所もの太字、見出しごとの絵文字。
- 直し方：かぎかっこは引用と固有名詞に使う。太字は1段落に1か所まで。

### D3. 感嘆符の多用（上限）
「！」は1つの文章に1回まで。説明文では使わない。

## E. 直した例

**材料（書き手から渡された事実）**
- 請求書の作成と送付を自動化するツール
- 社内計測で、月の請求作業が平均2日から半日になった（2026年4月、導入10社）
- 初期設定は管理画面で15分ほど
- 14日間の無料体験あり（クレジットカード登録不要）

**元の文**
> 業務効率化——それは、もはや選択肢ではありません。必須です。私たちのツールは、圧倒的なスピードを実現。設定不要。学習コストゼロ。変わります、あなたのチームの働き方が。さあ、新しい時代へ。

**直した文**
> 請求書の作成から送付までを自動化します。導入した10社では、月の請求作業が平均2日から半日になりました（2026年4月の社内計測）。初期設定は管理画面で15分ほどです。14日間の無料体験は、クレジットカードを登録せずに始められます。

**主な変更点**
- 対比の演出（「選択肢ではない。必須だ」）と、否定の列挙（「設定不要。学習コストゼロ」）を消し、材料にある事実に置き換えた。
- 「設定不要」は材料の「初期設定は15分ほど」と食い違うため、材料のほうに合わせた。「学習コストゼロ」は材料に根拠がないので消した。
- 「圧倒的なスピード」を、材料にある数値と計測の条件に置き換えた。
- 倒置（「変わります、〜が」）と決め台詞の締め（「さあ、新しい時代へ」）を消し、次に取れる行動で終えた。

材料に数値がなければ、「月の請求作業が[要確認: 導入前後の時間と計測条件]になりました」のように空欄を残して返す。
