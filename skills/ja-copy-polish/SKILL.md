# 日本語の文言を正確にする（ja-copy-polish）

AI が書いた日本語は、単語より文の形で見抜かれます。代表は、述語を省いた断片（「完全に。」）、語順を入れ替えた倒置（「変わります、働き方が。」）、根拠のない誇張の3つです。読み手は一度「AIっぽい」と感じると、書かれた中身まで疑います。このスキルは、文の形を整え、事実を正確に伝える文に直すためのものです。

## 最優先の3原則

1. **述語まで書く。** 文は「何が（誰が）・何を・どうする」で終える。「完全に。」で止めず、「請求書の作成と送付を自動化します。」のように、何がどうなるかまで書く。
2. **普通の語順で書く。** 倒置しない。「変わります、あなたの働き方が。」は「あなたの働き方が変わります。」にする。
3. **事実で語る。** 誇張語で盛らず、数字・固有名詞・具体的な動作で伝える。材料にない事実は作らない。

## 作業の手順

### 1. 依頼の種類を見分ける
- **新しく書く**：材料（製品、対象者、伝えたいこと、根拠になる事実）を集める。足りない事実は作らず、`[要確認: 導入社数]` のように空欄として示す。
- **直す（推敲）**：元の文の言葉選び、敬体・常体、長さは書き手の意図として尊重する。直すのは、下の書き癖に当たる箇所と、誤り・曖昧さだけにする。
- **一行だけ直す**：その一行だけを直す。周りに手を広げない。
- **指摘だけ**：書き換えず、該当箇所・理由・修正案を一覧で返す。

### 2. 事実を固定する
書き換える前に、元の文と渡された資料に含まれる事実（数字、固有名詞、条件、期限、価格、注意書き）を書き出す。これが「使ってよい事実」のすべてになる。書き換えた後に、すべてが残っているか、意味が変わっていないかを照合する。

- 文を良くするために、事実を足したり強めたりしない。
- 書き癖を直すために具体的な事実が必要なのに材料にない場合は、`[要確認: 具体的な効果の数字]` を置いて書き手に返す。
- 「設定不要」を「担当者が代行」に変えるような、意味の差し替えをしない。

### 3. 書き癖を直す
[references/patterns.md](references/patterns.md) の一覧に沿って直す。特に次の5つは、本文では1回でも出たら直す（見出しとキャッチコピーの扱いは「例外」を参照）。下の例の〇〇と数字は、材料にある事実を入れる場所を示す。

| 書き癖 | 悪い例 | 直した例 |
|---|---|---|
| 述語のない断片 | 「完全に。」「圧倒的なスピード。」 | 「〇〇を自動化します。」「処理時間を〇分から〇分にしました。」 |
| 倒置法 | 「届けたい、本当の価値を。」 | 「〇〇を通じて、〇〇を届けます。」 |
| 対比の演出 | 「ただのツールではありません。パートナーです。」 | 「導入後も、〇〇を支援します。」 |
| 否定の列挙 | 「設定不要。契約不要。待ち時間ゼロ。」 | 「設定をせずに使い始められます。契約は不要です。」 |
| 読点で溜める | 「静かに、確実に、進化する。」 | 「〇〇の機能を毎月追加しています。」 |

### 4. 表示上のリスクを確認する
マーケ文言では、文体より先にこれを確認する。根拠が材料に示されていない表現は、根拠の範囲で言える具体的な事実に書き換えるか、`[要確認: 根拠]` を付けて書き手に返す。根拠を自分で作らない。「ほぼすべて」「大幅に」のような言い換えも根拠が要るので、逃げ道に使わない。

- **最上級・断定**：「No.1」「業界初」「最安」「完全」「絶対」「必ず」「100%」「誰でも」。景品表示法の優良誤認・有利誤認にあたるおそれがある。調査の根拠が要り、注記を付けても、本文の表現が実際と違えば不当表示になりうる。「絶対」「必ず」「誰でも」は、根拠を示すのが難しいので、基本的に使わない。
- **効果・効能**：「治る」「痩せる」「シミが消える」など、病気の治療・予防や身体への作用をうたう表現。商品の種類（健康食品、化粧品、雑貨、美容機器など）を問わず、薬機法や健康増進法に触れるおそれがある。
- **価格・条件**：「今だけ」「無料」「返金保証」。期間、条件、例外を本文か、すぐ近くの注記に書く。
- **比較**：他社名を出した比較は、客観的な根拠と同じ条件での比較が要る。

このチェックは、明らかな危険を見つけるためのものです。法務の確認の代わりにはなりません。ステルスマーケティング規制、特定商取引法、二重価格表示などは対象に含めていません。公開する広告や LP は、必要に応じて法務の確認を受けてください。

### 5. 仕上げの確認
[references/checklist.md](references/checklist.md) で確認する。最後に、変更点ごとに「良くなったのか、変わっただけか」を問い、理由を言えない変更は元に戻す。

## 例外（直さなくてよいもの）

- **見出し、ボタン、メニュー、表のセル、箇条書きの項目**は、名詞で終えてよい（「料金プラン」「無料で試す」「導入事例」）。ただし、倒置と「〜。〜。」の断片の連続は使わない。
- **キャッチコピー**（ページの一番上の1行など）だけは、修辞（体言止め、倒置、対句）を1つだけ、意図して使ってよい。1つのページで1回までとし、本文には持ち込まない。
- **書き手の口調**（くだけた語、方言、業界用語）は、書き癖として扱わず、書き手の声として残す。
- 引用、固有名詞、法令で定められた表記は変えない。

## 出力の形

- 書き換えた文を先に出す。
- その後に、主な変更点を3〜5行で示す（「倒置を正順に」「根拠のない『No.1』に要確認を付けた」など）。
- 根拠の確認が必要な箇所は `[要確認: …]` として本文中に残し、最後にまとめて列挙する。
- 敬体（です・ます）と常体（だ・である）は、元の文か依頼に合わせて統一する。
